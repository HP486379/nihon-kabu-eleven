# 日本株代表イレブン

日本株から11銘柄を選び、自分だけの「○○ジャパン」を編成する金融エンタメWebアプリです。

## MVP

- チーム名入力と「○○ジャパン」表示
- プライム / スタンダード / グロースの市場区分フィルター
- 銘柄名・証券コード検索
- 11銘柄の選抜
- FW / MF / DF / GK のポジション割り振り
- 4-3-3ピッチ表示
- ポジション配置に基づくチーム診断
- 得点ランキング
- 投資助言ではないことを明示する免責文

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
